# 改善提案 - AV Scope

このドキュメントは、収益性、SEO、UI/UX、開発体験の4つの観点から改善すべき点をまとめています。

## 🎯 収益性（Monetization）

### 優先度: 高

#### 1. **アフィリエイトリンクのCTA最適化**
- **現状**: 「詳細」ボタンのみで、コンバージョン率が低い可能性
- **改善案**:
  - アフィリエイトリンクのボタンデザインを強化（色、サイズ、配置）
  - 「今すぐ購入」「詳細を見る」など、行動を促す文言に変更
  - 価格表示の強調（「¥1,980で購入」など）
  - アフィリエイトリンクを複数箇所に配置（ヘッダー、サイドバー、フッター）
- **効果**: クリック率10-30%向上が期待できる

#### 2. **コンバージョントラッキングの強化**
- **現状**: `trackAffiliateClick` は実装済みだが、より詳細な分析が必要
- **改善案**:
  - コンバージョンファネル分析（PV → 詳細 → アフィリエイトクリック → 購入）
  - A/Bテストの導入（ボタンデザイン、配置のテスト）
  - ホットスポット分析（どこがクリックされやすいか）
  - エンゲージメント指標の追跡（動画視聴時間、滞在時間）
- **効果**: データドリブンな改善により、コンバージョン率が向上

#### 3. **価格表示の最適化**
- **現状**: 価格は表示されているが、訴求力が弱い
- **改善案**:
  - 特売・セール情報の表示（「限定セール中」「お得な価格」など）
  - 割引率の表示（「20%OFF」など）
  - 価格比較機能（類似作品との価格比較）
- **効果**: 購買意欲を刺激

#### 4. **関連作品の収益化**
- **現状**: 関連作品は表示されているが、クリック率が低い可能性
- **改善案**:
  - 「この作品を見た人はこれも見ています」セクションの強化
  - 「おすすめ作品」セクションの追加（人気・高評価作品を優先表示）
  - 動画サンプル視聴後のアフィリエイトリンク強化
- **効果**: 関連作品からのクリック増加

### 優先度: 中

#### 5. **広告配置の検討**
- **現状**: 広告が配置されていない（または未確認）
- **改善案**:
  - Google AdSense などの広告枠追加（ページ下部、サイドバー）
  - ネイティブ広告の導入（コンテンツと調和した広告）
  - アフィリエイトリンクと広告の最適なバランス
- **効果**: 追加収益源の確保

#### 6. **プレミアム機能の検討**
- **改善案**:
  - お気に入りリストの共有機能（有料）
  - 詳細検索機能（有料）
  - 広告非表示機能（有料）
- **効果**: 新たな収益源の創出

## 🔍 SEO（Search Engine Optimization）

### 優先度: 高

#### 1. **キャッシュ戦略の最適化**
- **現状**: `next.config.ts` でキャッシュが完全に無効化されている
  ```typescript
  Cache-Control: no-cache, no-store, must-revalidate, max-age=0
  ```
- **問題点**:
  - サーバー負荷増加
  - レスポンス時間の悪化
  - Vercel料金の増加
  - Core Web Vitalsの悪化
- **改善案**:
  ```typescript
  // 静的コンテンツ: 長時間キャッシュ
  Cache-Control: public, max-age=31536000, immutable
  
  // 動的コンテンツ: 短時間キャッシュ
  Cache-Control: public, s-maxage=3600, stale-while-revalidate=86400
  ```
- **効果**: 
  - ページ速度向上（LCP 改善）
  - Vercel料金削減
  - 検索エンジン評価向上

#### 2. **画像最適化の強化**
- **現状**: `images.unoptimized: true` で画像最適化が無効化されている
- **改善案**:
  - Next.js Image Optimization の有効化
  - WebP/AVIF形式の自動変換
  - 遅延読み込み（Lazy Loading）の最適化
  - 画像サイズの最適化（srcset属性の活用）
- **効果**: 
  - ページサイズ削減（50-70%削減可能）
  - LCP 改善（画像読み込み速度向上）

#### 3. **構造化データの拡充**
- **現状**: Product、VideoObject、BreadcrumbList は実装済み
- **改善案**:
  - `Organization` 構造化データの追加（会社情報、ロゴ）
  - `WebSite` 構造化データの強化（検索ボックス機能）
  - `ItemList` 構造化データ（ランキングページ用）
  - `Review` 構造化データの詳細化（レビュー情報の充実）
  - `FAQPage` 構造化データの活用（FAQページがある場合）
- **効果**: リッチスニペット表示の可能性向上

#### 4. **内部リンク構造の最適化**
- **現状**: 関連作品・女優のリンクは実装済み（24-32リンク/ページ）
- **改善案**:
  - 階層構造の明確化（カテゴリ → 作品）
  - 関連キーワードの内部リンク強化
  - サイトマップの更新頻度向上
  - アンカーテキストの最適化（自然な文言）
- **効果**: クローラビリティ向上、インデックス効率化

### 優先度: 中

#### 5. **メタデータの改善**
- **現状**: 基本的なメタデータは実装済み
- **改善案**:
  - 各ページの description を160文字以内に最適化
  - タイトルの最適化（60文字以内、キーワード含む）
  - hreflang タグの追加（日本語サイトとして明示）
  - canonical URL の確認・修正
- **効果**: 検索結果でのクリック率向上

#### 6. **Core Web Vitals の改善**
- **現状**: パフォーマンス監視は実装済み（PerformanceMonitor）
- **改善案**:
  - LCP (Largest Contentful Paint) の改善（画像最適化、プリロード）
  - FID (First Input Delay) の改善（JavaScript の最適化）
  - CLS (Cumulative Layout Shift) の改善（画像サイズ指定、フォント読み込み）
  - Web Vitals の継続的監視とアラート設定
- **効果**: 検索エンジン評価向上、ユーザー体験向上

#### 7. **モバイル対応の強化**
- **現状**: レスポンシブデザインは実装済み
- **改善案**:
  - モバイルファーストデザインの確認
  - タッチターゲットサイズの最適化（44x44px以上）
  - モバイルページ速度の最適化
  - AMP の検討（モバイル検索結果での優位性）
- **効果**: モバイル検索での評価向上

## 🎨 UI/UX（User Interface & User Experience）

### 優先度: 高

#### 1. **アクセシビリティ（A11y）の改善**
- **現状**: 
  - SkipLink は実装済み
  - ARIA属性は一部のみ実装（58箇所）
  - セマンティックHTMLは一部実装
- **改善案**:
  - **ARIA属性の追加**:
    - `aria-label` の追加（ボタン、リンク、アイコン）
    - `aria-describedby` の追加（フォーム、エラーメッセージ）
    - `aria-live` の追加（動的コンテンツ更新時）
    - `role` 属性の適切な使用
  - **キーボードナビゲーション**:
    - フォーカス順序の最適化
    - フォーカスインジケーターの強化
    - キーボードショートカットの追加
  - **色のコントラスト**:
    - WCAG AA 基準の確認（4.5:1以上）
    - カラーブラインド対応の確認
  - **スクリーンリーダー対応**:
    - 画像の alt テキストの充実
    - 装飾的画像は `aria-hidden="true"` を設定
- **効果**: 
  - アクセシビリティスコアの向上（Lighthouse）
  - より多くのユーザーに利用可能
  - 法的リスクの軽減

#### 2. **ローディング状態の改善**

- **効果**: 体感的な速度向上、ユーザー満足度向上

#### 3. **エラーハンドリングの改善**
- **現状**: 
  - `ErrorState` コンポーネントは実装済み
  - 基本的なエラーハンドリングは実装済み
- **改善案**:
  - **エラーメッセージの具体化**:
    - 「エラーが発生しました」→「ネットワークエラーです。接続を確認してください」

  - **リトライ機能の強化**:

  - **エラーレポート機能**:
    - エラーの自動収集（Sentry など）

- **効果**: ユーザー体験の向上、エラー原因の特定

#### 4. **モバイルUXの改善**
- **現状**: レスポンシブデザインは実装済み
- **改善案**:
  - **スワイプ機能の強化**:
    - スワイプ検索ページの改善
    - カルーセルでのスワイプ操作
  - **タッチジェスチャー**:
